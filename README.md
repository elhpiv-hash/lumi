# Lumi

Казуальная аркада: светлячок летит через сумеречный лес и проскакивает между лианами.
Механика в основе флаппи — тап, клик или пробел дают импульс вверх, гравитация тянет вниз.

**Играть: https://elhpiv-hash.github.io/lumi/**

## Чем сделано

Чистый JavaScript, ES-модули, Canvas 2D. **Ни одной зависимости и ни одного сборщика.**
Ни одного файла ассетов: звук и музыка синтезируются через WebAudio, графика рисуется кодом.

## Управление

| | |
|---|---|
| тап / клик / `Space` | взмах |
| `M` или кнопка в углу | звук |

## Локальный запуск

ES-модули не грузятся с `file://`, поэтому нужен любой статический сервер:

```bash
python -m http.server 4341
```

Дальше `http://localhost:4341`.

## Как устроено

```
index.html
src/
  config.js          все настроечные числа в одном месте
  main.js            оркестрация и рендер
  engine/
    loop.js          фиксированный шаг 1/120 с интерполяцией
    canvas.js        координаты в мировых единицах, DPR, ресайз
    input.js         touch/mouse/keyboard -> одна команда «взмах»
    particles.js     пул частиц
    audio.js         эффекты на осцилляторах
    music.js         генеративная музыка на пентатонике
  game/
    player.js        физика светлячка
    obstacles.js     пул лиан, спавн по расстоянию
    difficulty.js    нарастание сложности от пройденного пути
    collision.js     круг против прямоугольника
    score.js         счёт и рекорд
    states.js        машина состояний и правила партии
    background.js    небо, боке, рама
  platform/
    storage.js       адаптер хранилища
```

Ключевые решения:

- **Мир меряется не в пикселях**, а в условных единицах. Игровое поле — всегда
  прямоугольник 60×100, каким бы ни был экран, поэтому баланс настраивается один раз.
- **Фиксированный шаг симуляции.** Физика не зависит от частоты кадров: партия при
  17 и при 240 fps совпадает бит в бит.
- **Пулы вместо аллокаций.** Лианы и частицы создаются на старте и переиспользуются —
  за час игры ноль новых объектов и ноль пауз от сборщика мусора.
- **Размер прохода выведен, а не подобран.** Он обязан быть больше удвоенной суммы
  дуги взмаха и радиуса игрока, иначе игрок, машущий по центру, физически обязан
  задеть кромку.
